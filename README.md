# 喵喵文生图

喵喵文生图是一个面向 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 的轻量插图扩展，也兼容 [TauriTavern](https://github.com/Darkatse/TauriTavern)。它目前仅支持 NovelAI，操作路径简洁，并保留大部分酒馆用户熟悉的聊天内生图方式：从消息中识别图片标签，按需生成插图，再把结果放回原来的位置。

## 生图指令

在「资源」页选择生图指令来源。内置模式把人格、对象、正文张数和彩蛋标记集中生成为普通任务参数，并将启用的提示词条目组装到 D0。点击铅笔编辑正文，保存后更新指令；取消不保存，恢复默认只修改草稿。条目按固定顺序分组，可分别展开和折叠。

彩蛋、彩蛋解析、自检和 NSFW 扩展可分别开关。彩蛋额外检查只在彩蛋与自检都生效时发送；自检中的 NSFW 检查由独立开关控制。性向只发送当前选中的一份文本。新配置的小标题默认关闭，旧配置迁移时保留原有开关值。

外部模式由酒馆世界书提供主 API 的绘图指令。「资源」页可编辑配套世界书的宏和选开条目。旧版自定义整段正文保留兼容编辑与组装，主动选择新树后保留完整旧配置备份。

副 API 模式在主 API 正文完成后，让独立的 OpenAI 兼容接口生成绘图 tag。内置电子幽灵 1.7 可直接使用。为当前存档填写固定角色 tag 后，副 API 会收到 `$角色名$` 与固定 tag 的对照表。模型在绘图 tag 中引用调用记号并补写本段的服饰、表情和动作，插件在发送给 NovelAI 前展开固定 tag。副 API Key 默认保存在当前设备的浏览器中，同一酒馆地址和副 API 地址下更新后仍可读取。

内置副 API 预设会发送当前 User 的人设，以及 Char 的角色卡描述、性格和场景，供模型理解正文和人物外观。自定义预设可以用 `{{用户人设}}` 和 `{{角色设定}}` 引用这些资料。选择「当前标签页」保存副 API Key 时，同一标签页刷新后仍可使用。跨标签页使用请选「此设备」。

## 使用前准备

- 一个可用的 NovelAI 账户和 API Key。
- 一份可以运行的 SillyTavern。

本扩展负责连接 SillyTavern 与 NovelAI，不提供 NovelAI 账户或生图额度。

## 安装

在酒馆的扩展管理中安装本仓库：

```text
https://github.com/AYUUKI-K/Meow-Text-to-Image
```

安装或更新后刷新酒馆页面，已打开的页面需要完整刷新才能载入新脚本。

安装后，从输入框旁的扩展菜单打开「喵喵文生图」。首次启用时，扩展使用内置生图指令并安装配套正则；已有外部世界书模式会保留。可在「资源」页切换来源和导入正则。

## 快速开始

1. 打开「生成」页，填写并保存 NovelAI Key。使用 Vibe 时，可选择是否在当前设备记住直连 Key；不记住时，刷新页面后需要重新填写。
2. 打开「配置」页，选择模型并调整提示词和生图参数。默认配置已经可以直接使用。
3. 在「资源」页选择生图指令来源。主 API 模式让模型按 `image###提示词###` 输出插图标签。例如：

   ```text
   image###1girl, sitting by a window, morning sunlight###
   ```

4. 手动模式下，点击楼层中的「生成插图」才开始生图。主 API 在回复中提供提示词。使用副 API 时，滚动到要出词的 AI 楼层，三击悬浮球获取提示词，再点击「生成插图」。

每个标签中的内容作为本次场景提示词。多个标签会分别生成图片。若你使用其他标签格式，可在「资源」页设置起始标签和结束标签。

## 生图设置

「生成」页包含自动化和连接设置：

- **手动模式**下，点楼层中的「生成插图」才开始生图。副 API 手动模式会固定显示悬浮球，三击给当前看到的 AI 楼层出词。
- **回复后生成**：新回复结束后自动生成其中的图片标签。
- **流式生成**：回复仍在输出时，只要完整图片标签已经闭合，就可以开始生成。

自动模式只处理启用期间产生的最新 AI 回复，不会因为打开聊天或切换模式就自动补跑历史标签。历史消息仍可通过生成按钮手动处理。多个任务在本页依序执行；可选启用共享 Key 排队，以协调使用相同 Key 的请求。队列只用于安排请求，具体设置见[队列说明](docs/QUEUE.md)。

无论是否启用云端排队，每次实际发送生图请求前都会随机等待 2～4 秒，包括自动重试；多张图片仍按本地串行队列依次生成。HTTP 429 临时限流后的自动重试仍至少等待 10 秒，默认生图超时仍为 60 秒。

「配置」页中的每套配置保存独立的模型、提示词、画布尺寸、步数、Guidance、种子、采样器、噪声表和可用的 Vibe。可以新增、复制、删除、切换配置，也可以导入或导出 NAI 配置文件。配置例图用于快速查看不同配置的大致效果；生成例图同样会调用 NovelAI。

「配置选择 → 选择方式」默认使用单个配置；点击例图即可切换当前生图与编辑配置。选择「多个配置（每张图随机）」并通过例图选中至少两个配置后，每张普通插图会独立、等概率使用其中一套完整配置。选中配置名称前显示 `♡`；多配置模式下，点击例图切换随机池选择，点击铅笔只切换编辑对象，可以编辑未入池的配置。候选不足两个时会提示，普通图片暂不能生成；新增、复制或导入的配置不会自动入池。下方「编辑配置」的例图刷新、放大和参数修改仅操作当前编辑对象。开启「为最后一张图（彩蛋）单独指定配置」后，每条助手回复的最后一个完整正文图片标签使用指定配置；只有一张图时也适用。彩蛋分隔标记读取插件基础配置的「彩蛋标签」（外部模式沿用已保存值），只识别图片标签和思维链之外的独立一行；缺失或有歧义时按正文尾图处理。流式模式开启尾图覆盖时只保留最后一个候选到回复结束，其余图片依次生成。排队和自动重试沿用首次入队时选定的配置与参数；手动重新生图会重新选择。

Vibe 可在「Vibe」页导入官方文件、JSON、ZIP 或图片，再在配置中选择使用。Vibe 仅适用于 V4 和 V4.5 模型；支持随机选一个候选，或同时使用最多四个。导入、编码、设备保存及模型支持范围详见 [Vibe 使用说明](docs/VIBE.md)。

## 自定义 NovelAI 兼容接口

在「生成」页切换连接方式，填写第三方站点的基础 API 地址或完整生图端点和 API Key。默认自动补全 `/ai/generate-image`，也可选择原样使用完整地址。Vibe 编码地址可从生图地址推导、手动覆盖或禁用；自动推导只表示路径预测，不代表第三方站点支持编码。官方与自定义凭证分别保存。

详细配置、浏览器网络限制及诊断码见[连接设置与错误排查](docs/CONNECTIONS.md)。

## 图库和图片保存

生成的原图保存在酒馆用户的图片目录中，聊天消息保存图片引用和生图记录。图库可按角色、聊天和日期浏览图片，支持放大查看、下载、批量选择和清理。删除原图也会使引用它的聊天图片失效，请在确认后再清理。

缩略图用于加快图库列表显示，不会替代原图。「刷新列表」会重新读取图片，并为缺少缩略图的旧图片补建缓存；已有缩略图会复用。此操作不会调用 NovelAI。

通过手机访问电脑上运行的 SillyTavern 时，图片仍保存在电脑端的酒馆目录。各平台的实际文件位置见[图片分类与存储位置](docs/ARCHIVES.md)。

## 世界书和正则

内置指令提供让模型输出图片标签的提示规则，正则负责清理上下文标签。首次启用安装配套正则。可在「资源」页导入正则或更新配套世界书。

切换来源不会关闭或删除已有世界书，请避免同时启用重复指令。两种模式都保留自定义捕捉标签；内置正文默认使用 `image###` / `###`，捕捉设置不一致时面板会提示，请核对设置与实际输出。

## 常见问题

**回复里有标签，但没有生成按钮。** 确认配套正则已启用，消息符合起始和结束标签格式，并检查「资源」页当前捕捉标签是否与输出一致。

**自动模式没有处理旧图片标签。** 自动模式只处理启用后新产生的最新 AI 回复。打开旧聊天时，请点击该标签旁的生成按钮。

**使用 Vibe 时提示连接失败。** Vibe 生图使用当前选择的官方或自定义连接，请确认已保存该连接的可用 Key，且当前设备能访问对应生图接口；在线编码还需要该连接支持编码接口。

**更新后界面看起来没有变化。** 更新插件文件后完整刷新酒馆页面；已打开的标签页会继续运行刷新前载入的脚本。

**想备份图片或设置。** 配置、Vibe、聊天引用和原图分别由酒馆保存。迁移或重装时请保留原酒馆用户数据；图片目录和各类文件位置见[图片说明](docs/ARCHIVES.md)。

## 调用费用

生图、Vibe 在线编码和例图生成可能消耗额度，具体以当前服务和账号的计费规则为准。测试生图会实际调用接口；导入已有编码的 Vibe、导入配置和查看本地图库不会额外生图。
