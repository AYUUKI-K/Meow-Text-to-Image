# 喵喵文生图

喵喵文生图是一个面向 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 的轻量插图扩展，也兼容 [TauriTavern](https://github.com/Darkatse/TauriTavern)。它目前仅支持 NovelAI，操作路径简洁，并保留大部分酒馆用户熟悉的聊天内生图方式：从消息中识别图片标签，按需生成插图，再把结果放回原来的位置。

## 使用前准备

- 一个可用的 NovelAI 账户和 API Key。
- 一份可以运行的 SillyTavern。

本扩展负责连接 SillyTavern 与 NovelAI，不提供 NovelAI 账户或生图额度。

## 安装

在酒馆的扩展管理中安装本仓库：

```text
https://github.com/AYUUKI-K/Mewo-Text-to-Image
```

安装或更新后刷新酒馆页面，已打开的页面需要完整刷新才能载入新脚本。

安装后，从输入框旁的扩展菜单打开「喵喵文生图」。首次启用时，扩展会载入配套的默认世界书和正则规则；也可以在「资源」页检查、更新或导入自己的资源。

## 快速开始

1. 打开「生成」页，填写并保存 NovelAI Key。使用 Vibe 时，可选择是否在当前设备记住直连 Key；不记住时，刷新页面后需要重新填写。
2. 打开「配置」页，选择模型并调整提示词和生图参数。默认配置已经可以直接使用。
3. 在世界书或你自己的提示词模板中，让模型按 `image###提示词###` 输出插图标签。例如：

   ```text
   image###1girl, sitting by a window, morning sunlight###
   ```

4. 手动模式下，点击消息中的「生成插图」按钮即可生图。生成完成后，图片显示在该标签原来的位置。

每个标签中的内容作为本次场景提示词。多个标签会分别生成图片；插件不会替你改写场景内容。若你使用其他标签格式，可在「资源」页设置起始标签和结束标签，捕捉到的第一段内容会作为提示词。

## 生图设置

「生成」页包含自动化和连接设置：

- **手动**：消息中显示生成按钮，由你选择何时生图。
- **回复后生成**：新回复结束后自动生成其中的图片标签。
- **流式生成**：回复仍在输出时，只要完整图片标签已经闭合，就可以开始生成。

自动模式只处理启用期间产生的最新 AI 回复，不会因为打开聊天或切换模式就自动补跑历史标签。历史消息仍可通过生成按钮手动处理。多个任务在本页依序执行；可选启用共享 Key 排队，以协调使用相同 Key 的请求。队列只用于安排请求，具体设置见[队列说明](QUEUE.md)。

「配置」页中的每套配置保存独立的模型、提示词、画布尺寸、步数、Guidance、种子、采样器、噪声表和可用的 Vibe。可以新增、复制、删除、切换配置，也可以导入或导出 NAI 配置文件。配置例图用于快速查看不同配置的大致效果；生成例图同样会调用 NovelAI。

Vibe 可在「Vibe」页导入官方文件、JSON、ZIP 或图片，再在配置中选择使用。Vibe 仅适用于 V4 和 V4.5 模型；支持随机选一个候选，或同时使用最多四个。导入、编码、设备保存及模型支持范围详见 [Vibe 使用说明](VIBE.md)。

## 图库和图片保存

生成的原图保存在酒馆用户的图片目录中，聊天消息保存图片引用和生图记录。图库可按角色、聊天和日期浏览图片，支持放大查看、下载、批量选择和清理。删除原图也会使引用它的聊天图片失效，请在确认后再清理。

缩略图用于加快图库列表显示，不会替代原图。「刷新列表」会重新读取图片，并为缺少缩略图的旧图片补建缓存；已有缩略图会复用。此操作不会调用 NovelAI。

通过手机访问电脑上运行的 SillyTavern 时，图片仍保存在电脑端的酒馆目录。各平台的实际文件位置见[图片分类与存储位置](ARCHIVES.md)。

## 世界书和正则

配套世界书提供让模型输出图片标签的提示规则，正则负责清理上下文标签。首次启用会载入内置资源。你可以在「资源」页更新它们，或在酒馆内导入自己的世界书或正则，也可以设置自定义起止标签。

资源更新会按条目 ID 或名称合并已有内容，并保留用户添加的世界书条目。插件不会自动关闭酒馆中的其他世界书；是否启用资源仍可在酒馆自己的世界书和正则管理界面中调整。

## 常见问题

**回复里有标签，但没有生成按钮。** 确认配套正则已启用，消息符合起始和结束标签格式，并检查「资源」页当前捕捉标签是否与输出一致。

**自动模式没有处理旧图片标签。** 自动模式只处理启用后新产生的最新 AI 回复。打开旧聊天时，请点击该标签旁的生成按钮。

**使用 Vibe 时提示连接失败。** Vibe 生图需要当前浏览器能访问 NovelAI，并且扩展中保存了可用的直连 Key。

**更新后界面看起来没有变化。** 更新插件文件后完整刷新酒馆页面；已打开的标签页会继续运行刷新前载入的脚本。

**想备份图片或设置。** 配置、Vibe、聊天引用和原图分别由酒馆保存。迁移或重装时请保留原酒馆用户数据；图片目录和各类文件位置见[图片说明](ARCHIVES.md)。

## Anlas 与 Opus

NovelAI 官方说明：Opus 订阅下，单张生成、不使用输入底图、画布为普通尺寸或更小且步数不超过 28 时，生图通常不扣 ImageAnlas。插件每次只发送一张图，内置尺寸预设都在普通尺寸范围内；最多启用四个 Vibe，也不会触发官方“超过四个后每个额外 Vibe 增加 2 ImageAnlas”的费用。详见 [NovelAI 订阅说明](https://docs.novelai.net/en/subscription/) 和 [Vibe Transfer 说明](https://docs.novelai.net/en/image/vibetransfer/)。

Vibe 图片编码另有一次性费用，按 NovelAI 规则通常为每个编码 2 ImageAnlas；导入已经编码好的 Vibe 可避免重复编码。V5 在 Opus 下的普通尺寸、28 步以内生成还会消耗官方持续恢复的使用额度；额度耗尽后，继续生成可能会扣除订阅或已购 Anlas。更大画布或超过 28 步的生成也可能产生 Anlas 费用。具体费用以 NovelAI 账户和官网当前规则为准。
