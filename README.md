## 安装

在酒馆「扩展程序 → 安装扩展程序」粘贴：

```text
https://github.com/AYUUKI-K/Mewo-Text-to-Image
```

安装后刷新页面，点击聊天输入框旁的魔棒，在菜单中打开「喵喵文生图」。原版酒馆需要后端支持 `/api/novelai/generate-image` 和 NovelAI 密钥管理。TT 酒馆使用设备直连 NAI，在插件中填写并保存 Key 后使用；勾选记住后可在刷新后恢复。

## 使用

1. 输入自己的 NovelAI API Key，点击保存。密钥存入酒馆密钥管理。
2. 在「配置」页设置模型、正面与负面提示词、画布大小和生成参数；支持复制、删除和切换多套配置。
3. 默认模式下，AI 输出的 `image###提示词###` 转成「生成插图」按钮，点击后开始生成。
4. 在「生成」页选择最新楼层的处理方式：手动、自动（开启期间的新回复完成后）、流式（完整标签闭合后）。自动和流式均只处理开启期间的新回复；旧标签、关闭期间的标签只显示手动按钮，不在开启、换模式或重载聊天时补跑。
5. 首次启用自动载入默认世界书与四份配套正则，也可以导入自己的世界书和正则。使用不同输出格式时，需要修改捕捉表达式，第一捕获组为绘图提示词。

最终正面按「前置正面 → 本次图片提示词 → 后置正面」拼接，负面单独发送。旧配置的正面保留在前置，后置默认为空。图片保存在酒馆图片目录，路径与生成参数记录在消息中；历史旧楼层不会自动生成；最新楼层按所选模式处理。

生图错误使用酒馆提醒，标明出错来源、可识别的原因及原始 HTTP 状态。普通酒馆若只返回不含详情的 500，会提示查看运行酒馆的终端日志；不能仅凭 500 判断 Key 被占用。服务提供的错误说明会隐藏已知密钥与 Bearer 凭据后显示。

例图使用 NovelAI 生图，按正常图片计费。保存配置后，仅在例图缺失或效果相关配置变化时生成；例图提示词修改后，其他串会标记待更新，保存该串或手动刷新后更新。随机 Vibe 的例图固定使用第一个候选，便于比较。

图片页支持按角色卡、聊天存档分类浏览，更新前端即可使用，无需安装额外后端或运行脚本。图片仍保存在原目录，分类说明见 [ARCHIVES.md](ARCHIVES.md)。

## 资源管理

内置世界书由 NUE-喵喵电波编写，当前内容为 2.2.2。在「资源」页点击「检查资源更新／更新资源」。已有 2.0／2.1／2.2／2.2.1 会升级为「[喵喵]文生图 2.2.2」：同标题条目替换为新版，保留条目编号和用户额外条目；全局、角色、用户角色与聊天绑定同步迁移。若多个历史版本已同时存在，会合并为一份 2.2.2；确认绑定保存后移除旧名，不留两本。其他历史聊天在打开时迁移旧绑定。

四份正则按 ID 或名称覆盖；喵喵文生图配套规则还会识别旧日期后缀并去重，避免 0820、0511 与 1024 重复执行。导入自定义世界书的同名条目、同名或同 ID 正则也会更新。资源更新不会自动关闭其他世界书。

插件总开关控制图片处理。已导入的世界书与正则可在酒馆各自的管理面板停用。

## 服务器存储与按日期清理

图片保存在酒馆服务器，浏览器不保存图片本体。在魔棒 → 喵喵文生图 → 图片页，可以修改 `user/images` 下的子目录（默认 `miao-nai`）；修改只影响之后生成的图片，旧目录仍可从管理目录中选择，不自动搬迁旧文件。所有模式使用酒馆标准图片接口，角色与聊天分类只改变图片页的显示。不提供任意绝对路径或 S3 配置。

按日期显示本插件生成图片数量，可清理单个日期或勾选多个日期批量清理。日期按访问设备时区归类。只识别本插件 `miao-时间戳` / `test-时间戳` / `sample-时间戳` 命名的 PNG，兼容初版文件。删除前确认数量，永久清理服务器文件后，引用原图的历史聊天将不能显示它；仍可手动重新生成。清理不会删除整个聊天或同目录中的其他图片。
