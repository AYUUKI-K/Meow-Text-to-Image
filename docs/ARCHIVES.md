# 图片管理与存储

生成图片保存在当前酒馆用户的数据目录中，聊天记录保存图片引用和生成信息。手机通过局域网连接电脑上的酒馆时，原图在电脑端，下载或分享后才会在手机上另存副本。

## 浏览和分类

在插件的图片页中，可以按「全部图片 → 角色卡 → 聊天存档」浏览，查看、下载和清理当前范围内的图片。

分类只是浏览方式，不会创建实体角色子目录，也不会移动或重命名已有图片。新图片按提交任务时的角色和聊天记录归属；同名角色按角色卡文件区分，群聊单独分类。

旧图片在打开对应聊天后补充归属，暂时无法确定来源的图片显示为「未分类」。复制聊天不会将已有图片改归到新聊天。配置例图单独显示，不混入普通聊天分类。

## 查看与重新生成

点击图片可放大查看；有生成记录的图片可以查看提示词、参数和实际使用的 Vibe。重新生成会保留原版本，可在同一位置切换已有版本。

删除原图后，引用它的聊天图片也会失效。按日期清理、删除和批量操作前，请核对当前目录及选择范围。需要备份时，先下载原图，并保留酒馆用户数据。

缩略图只用于加快列表显示，不替代原图。刷新列表会重新读取图片并为缺少缩略图的图片补建缓存，不会重新生图。PNG／JPG 导出可在存储设置中选择；转换失败时会提示错误。

## 配置例图与分享

在配置页保存共用的例图提示词后，保存配置会在例图需要更新时加入生图队列。例图固定使用 512×512 方图，不改变聊天生图的画布和提示词。点击「刷新例图」会重新生成，可能消耗额度；随机 Vibe 的例图使用首个候选，便于比较配置。

导出 NAI 串时可携带当前例图，与提示词和参数一起分享，不带 Key 或 Vibe 引用。例图导出副本会缩小并压缩，不修改原图；导入后保存到接收方酒馆，不额外生图。没有例图的配置文件也可以导入。

配置导出本来就包含提示词和参数，分享前请核对这些内容。它不是不含用户内容的诊断文件。

## 原图在哪里

以下以默认用户 `default-user`、插件默认目录 `miao-nai` 为例。自定义用户、数据根目录或存储目录会改变实际位置。

| 使用方式 | 原图位置或获取方式 |
| --- | --- |
| 电脑运行普通 SillyTavern | `酒馆目录/data/default-user/user/images/miao-nai/` |
| 安卓 Termux 运行 SillyTavern | 通常为 `~/SillyTavern/data/default-user/user/images/miao-nai/` |
| 手机连接电脑上的 SillyTavern | 原图仍在电脑端，通过插件下载到手机 |
| TauriTavern | 位于 TT 配置的数据根目录下，通常对应 `default-user/user/images/miao-nai/`；可使用插件下载或 TT 的导出功能 |

安卓系统可能限制文件管理器读取应用数据目录，iOS 的应用私有目录通常也不能直接用「文件」App 浏览。优先使用插件的下载、分享或 TT 提供的数据导出入口；不要依赖跨版本固定不变的系统目录。

在 iOS 分享面板中，可按系统提供的选项选择「存储到文件」或「存储图像」。若 JSON 导出文件名被分享目标替换为随机字符，可从插件导出区复制完整文件名后重命名；文件内部的配置名称不受外部文件名影响。

## 备份建议

图片、聊天引用、配置和 Vibe 分别保存，单独复制图片目录不能还原全部聊天与设置。迁移酒馆或重装前，按宿主的备份方式保存用户数据；跨设备分享配置或 Vibe 时，使用插件相应的导出功能。
