# Vibe 使用说明

Vibe 用于在生图时参考已有图片的风格。Mewo 可以导入已有编码的 Vibe 文件，也可以导入原图后在线编码。无需安装额外的酒馆服务端插件。

## 导入和使用

1. 在「生成」页保存当前连接的 API Key；官方和自定义连接的凭证分别保存。
2. 打开「Vibe」页，点击「导入 Vibe / 图片」，选择 `.naiv4vibe`、`.naiv4vibeBundle`、JSON、ZIP 或 PNG/JPEG/WebP 图片，可一次选择多个文件。
3. 打开「配置」页，选择支持 Vibe 的 V4／V4.5 模型，在生成参数下方开启「启用 Vibe」，展开使用方式、候选与强度设置。
4. 选择 Vibe 条目、与当前模型匹配的编码和参考强度，再提交生图任务。

已有匹配编码的文件可直接使用。只有原图、尚未编码的条目，需要先完成在线编码。模型或编码不匹配时会提示错误，不会静默忽略参考图。

## 在线编码

选中带原图的 Vibe，选择编码模型和信息提取量，再点击编码按钮。在线编码会实际调用服务，可能消耗额度；收费规则以当前服务为准。相同条目、模型和信息提取量已有编码时会复用缓存。

| 连接方式 | 编码请求发送位置 |
| --- | --- |
| 官方 NovelAI | 官方编码端点，使用本设备可用的官方 Key |
| 自定义兼容接口 | 单独配置的「Vibe 编码完整 URL」，使用自定义 Key |

自定义连接没有配置编码 URL 时，在线编码入口禁用，仍可导入并使用已有匹配编码的 Vibe；不会自动回退到官方编码接口。详见[连接设置](CONNECTIONS.md)。

## 随机与多个参考

每套配置可选择以下方式：

- **随机 1 个**：从勾选的候选池中抽取一个 Vibe，每个插图位置独立抽选。重新生成会再次抽选，可能得到同一个。
- **多个（最多 4 个）**：同时发送勾选的 Vibe，最多 4 个。切换到此模式前，需要将选择数量控制在上限内。

排队期间不会重新抽选；本次发送的是提交任务时确定的 Vibe。每套配置独立保存选择和强度。关闭「启用 Vibe」会保留原选择，重新开启即可恢复。

当前支持 V4／V4.5；切换到不支持的模型时，Vibe 入口会置灰。第三方站点可能有更严格的参考数量或模型限制，请按站点文档手动调整，Mewo 不会自动减少参考数量。

## 批量导出与备份

在「Vibe」页点击「批量导出 Vibe」，勾选条目后点击「导出选中 Vibe」，可打包成 ZIP。接收方直接导入 ZIP，无需先解压。

导出包含名称、已有模型编码、已有原图和缩略图，不包含 API Key、本机条目 ID 或配置中的参考强度。没有原图的条目不会补生成原图。导入产生新条目，不覆盖原列表；重复导入会再次添加条目。

库内最多保存 128 个 Vibe。一次导入或导出最多 128 个；导入文件总大小及 ZIP 解压内容最多 64 MB，单个内容文件最多 18 MB。文件校验失败时不会开始保存；若保存过程中酒馆连接或存储失败，会提示已经保存的数量，可刷新列表检查。

导入、导出已有文件不会调用生图或编码接口。导出的文件可能包含参考原图和风格编码，分享前请确认内容适合公开。

## 凭证与文件位置

「记住 Key」仅作用于当前设备的凭证存储；不勾选时，直连 Key 仅在本次页面暂存，刷新后需要重新填写。勾选后仍需保存新输入的 Key。取消记住会移除设备持久凭证，「清除 Key」还会清除当前页面的直连凭证。

Vibe 文件保存在酒馆当前用户的 `user/files/miao-vibe-*.json`，扩展设置保存列表摘要。手机连接电脑上的酒馆时，文件在电脑端；换设备登录同一酒馆用户仍可读取列表，但设备凭证需要单独配置。

Vibe 生成使用当前连接的生图 URL，图片按原有保存流程处理。云端队列只接收排队所需的指纹与任务状态，不接收 Key、原图、提示词或编码。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 刷新后有 Vibe 列表，但提示 Key 不可用 | 在当前设备重新填写并保存当前连接的 Key；列表和凭证分别存储。 |
| 提示缺少模型编码 | 选择匹配的模型或编码；条目有原图时可为目标模型在线编码。 |
| 自定义接口无法点击编码 | 在连接设置中填写独立的 Vibe 编码完整 URL。 |
| 导入失败或部分条目未保存 | 查看错误提示，检查格式、文件大小、数量上限及酒馆存储连接，再刷新列表。 |
| 第三方站点拒绝参考数量或参数 | 按站点返回说明调整选择，不能将插件上限当作站点承诺。 |
